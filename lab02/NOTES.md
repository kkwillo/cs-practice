рабочая папка - это папка проекта на диске, где я вижу и редактирую файлы

индекс - промежуточная область между рабочей папкой и коммитом

коммит - зафиксированный список проекта

Git - это программа на моем компьютере

Github - сайт для хранения Git-репозиториев и совместной работы

git status - показывает состояние

git diff - показывает изменения

git diff --staged - показывает подготовленные изменения

ветка - это указатель на коммит. При новом коммите указатель сдвигается на него, а другие ветки остаются на своих местах, история развивается параллельно.
